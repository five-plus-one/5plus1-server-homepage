### 01 — 选择你的世界

生存世界适合探索、采集与聚落建设；创造世界适合建筑、装饰和投影辅助建造。下载所选服务器对应的 Windows 客户端，两个客户端分别解压到独立文件夹。

### 02 — 准备游戏账号

无论是否拥有正版账号，都请前往 [5plus1 皮肤站](https://skin.mc.five-plus-one.com) 注册账号，创建游戏角色并设置皮肤。

### 03 — 启动客户端

打开 HMCL.exe，在账号管理中添加 5plus1 Skin 账号，使用皮肤站的账号和密码登录，然后启动游戏。首次启动会联网下载游戏与模组，后续启动时检查整合包更新。

生存世界使用 Minecraft 26.2，需要 Java 25；创造世界使用 Minecraft 1.21.1，需要 Java 21。可按启动器提示安装，或选择已安装的对应版本。

### 04 — 添加服务器

进入游戏后，打开「多人游戏 → 添加服务器」。名称可自行填写，地址对应所选世界：

- 生存世界：`server26.mc.five-plus-one.com`
- 创造世界：`creative26.mc.five-plus-one.com`

生存服可用 `/warps` 查看传送点。创造服的 WorldEdit 指令与投影批量粘贴需要对应权限，使用前请向管理员确认。连接前请阅读服务器公约。
